# 🪔 Diwali Sales Analysis using Python

Analyze Diwali sales data to uncover customer insights and improve business performance.
This beginner-friendly project demonstrates the complete data analysis process — from cleaning and exploration to visualization and insights.

## 📊 Project Overview

This project focuses on **analyzing Diwali sales data** using Python to understand:

* Customer purchasing behavior
* Sales trends across states, occupations, and age groups
* Factors influencing high-value transactions

By the end, the goal is to help improve **marketing strategies and customer experience**.
## 🧰 Tools & Libraries Used

* **Python** 🐍
* **Libraries:**

  * pandas → for data cleaning and analysis
  * numpy → for numerical operations
  * matplotlib & seaborn → for visualization
  * jupyter notebook → for code execution and exploration
## 🧾 Dataset

**File:** `Diwali Sales Data.csv`
**Description:**
The dataset contains customer purchase information during Diwali.
Key columns include:

* `Gender`, `Age Group`, `State`, `Occupation`
* `Product_Category`, `Orders`, `Amount`

---

## 🔍 Steps Performed

1. **Data Cleaning**

   * Removed null values
   * Dropped unnecessary columns
   * Fixed data types

2. **Exploratory Data Analysis (EDA)**

   * Gender-wise and age-wise spending analysis
   * Top performing states
   * Most popular product categories and occupations

3. **Visualization**

   * Bar plots and count plots for comparing categories
   * Insights derived from customer segments

## 💡 Key Insights

* **Females** tend to purchase more than males.
* **Age group 26–35 years** contributes the most to sales.
* **Top states:** Uttar Pradesh, Maharashtra, and Karnataka.
* **Top occupation categories:** IT, Healthcare, and Aviation.

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/<your-username>/Python_Diwali_Sales_Analysis.git
   ```
2. Navigate to the project folder:

   ```bash
   cd Python_Diwali_Sales_Analysis
   ```
3. Install dependencies:

   ```bash
   pip install pandas numpy matplotlib seaborn
   ```
4. Open Jupyter Notebook:

   ```bash
   jupyter notebook
   ```
5. Run the notebook:
   `Diwali_Sales_Analysis.ipynb`
